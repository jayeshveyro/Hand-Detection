# Hand Tracking 
It is a open-source Hand tracking project built to track multiple hand gestures. It uses "Open-cv" to access to camera and "Mediapipe" for drawing the dots and tracking the hand. The project is built on Python 3.14. It can be advanced in future to control or perform actions based on the hand gestures.

# Libraries Required
### 1. Opencv-python
### 2. Mediapipe

# Steps to build
1.Create a folder called "Hand Tracking"\
2. Downlod and paste the file "hand_landmarker.task" into the project folder.\
3. Open Terminal inside the folder and run "python -m venv .venv" to create a virtual environment.\
4. Run the command ".venv\Scripts\activate" to activate the environment.\
5. Run the command "pip install mediapipe opencv-python" to install the opencv and mediapipe libraries.\
6. Downlod the "main.py" file and paste it in the project folder.\
7. Run the command ".\.venv\Scripts\python.exe main.py" to start running the project.
